# Workspace Guide (README)

Generated by affine-sync. Machine-managed; do not hand-edit (changes are overwritten).

## What this workspace is

Source of truth for documentation across all repos; each repo's `docs/` tree is a
local mirror. Structure: `<repo>/<feature>/<doc>`. Kept fresh by affine-sync
(a live push while docs are written, plus a deterministic Stop-hook backstop).
Commit policy: `docs/**` is gitignored; promote a doc with `git add -f`.
Engine: `~/.claude/tools/affine-sync`. Config: `~/.claude/affine-sync/config.json`.

## Conventions

- kinds: `spec`, `plan`, `review`, `notes`, reference docs (`<name>.md`), and
  dated `handoffs/` and `errata/` subfolders.
- Titles: `"<feature> - <kind>"`. Identity: per-repo state file + a `syncKey`
  custom property; never the title.
- Front-matter overrides: `title`, `order`, `skipSync`.
